## 🧠 Roadmap de Aprendizaje

### 1. Fundamentos de JavaScript

- Variables (var, let, const)
- Tipos de datos primitivos
- Operadores
- Condicionales (if, else, switch)
- Loops (for, while, do-while)
- Funciones (declaradas, expresadas, arrow functions)
- Arrays y métodos de arrays
- Objetos y métodos

### 2. Conceptos Avanzados

- Asincronía: callbacks, promesas, async/await
- Manipulación de la Fetch API
- Introducción a clases y prototipos
- Modularización del código
- Manejo de errores

### 3. Práctica con Proyectos

- ToDo List App
- Calculadora básica
- Aplicación del clima usando una API pública

### 4. Recursos y Ampliación

- Libros recomendados
- Cursos en línea
- Documentación oficial
